REAL-WORLD HARDWARE

Built on a
Galaxy A10e.

Chelus’s agent runtime, tools, conversations, memory, and skills run on the phone. The core uses Python’s standard library, with no pip dependencies.

A 32-bit Termux environment is the demonstrated platform. With Termux:Boot it comes back on its own after a reboot. The small footprint is a constraint we build around, not a limit on useful work.

Agent on your device.
Inference via DeepSeek or another OpenAI-compatible API.
